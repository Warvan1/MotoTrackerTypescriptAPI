# MotoTrackerAPI
MotoTrackerAPI is a Typescript Express.js app that is used as the backend for the Mototracker Java app and the Mototracker Next.js website connecting them to a postgresql database.
Java App: [GitHub](https://github.com/Warvan1/MotoTracker)
Next.js Website: [GitHub](https://github.com/Warvan1/MotoTrackerWebsite)
